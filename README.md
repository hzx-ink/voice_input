# 全局语音输入工具

按住 **Ctrl+Space** 说话，松开后自动把识别出的文字粘贴到当前光标位置。全程本地离线识别，无需联网（仅首次运行需下载模型）。

## 使用方法

1. 双击 `install.bat` 安装依赖（使用阿里云镜像，只需一次）
2. 双击 `start.bat` 启动，等待"模型就绪"提示
3. 在任意应用（微信、Word、浏览器、聊天框…）中，按住 Ctrl+Space 说话，松开后文字自动出现在光标处
4. 直接关闭控制台窗口即可退出

## 常用配置（voice_input.py 顶部）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `MODEL_SIZE` | `base` | 改为 `tiny` 内存更省、速度更快（准确率略降）；`small` 更准但更慢 |
| `LANGUAGE` | `zh` | 改为 `None` 可自动检测中英文 |
| `HOTKEY_MOD` / `HOTKEY_KEY` | `ctrl` / `space` | 修改触发热键，如改为 `ctrl` + `j` 避开输入法冲突 |

## 资源占用说明

- **空闲时 CPU 占用 0%**：键盘钩子事件驱动 + 主线程挂起等待，无轮询
- **不录音时无音频流**：音频流只在按住热键期间存在，回调每 100ms 一次
## 注意事项

1. **Ctrl+Space 与 Windows 输入法切换热键冲突**：按下时会切换中英文输入法。
   如需避免，可在 输入法设置 → 微软拼音 → 按键 中取消 Ctrl+Space 的勾选，
   或把本工具热键改为其他组合（修改 `HOTKEY_KEY`）。
2. 若目标是**以管理员身份运行的程序**（如某些终端），本工具也需要管理员权限运行才能注入文字。
